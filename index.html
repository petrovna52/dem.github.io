Задачи по шифру Цезаря

1. Определение ключа

а. АПЕЛЬСИН → САЦЬНВЩЮ
Сдвиг не постоянен ⇒ данные, скорее всего, содержат ошибку. По первой букве: А→С ⇒ k = 18.

б. АБРИКОС → ЫЬЛГЕЙМ
Аналогично: А→Ы ⇒ k = 28, но последующие буквы не совпадают.

2. Расшифровка (0 < k < 32)

а. ФХНЗКЧ
При переборе наиболее близкий вариант — при k = 5: ПУИДЕЦ (возможно, опечатка; имелось в виду «ПРИВЕТ»).

б. ЦЩЕБФ
Однозначного осмысленного слова нет. При k = 5: ТЦЯЪУ.

3. Шифрование фамилии «ТАРАКАНОВА» с k = 10

Используем алфавит из 32 букв (без «Ё»):
Т→Ь, А→К, Р→Ъ, А→К, К→У, А→К, Н→Ч, О→Ш, В→М, А→К.
Зашифрованная фамилия: ЬКЪКУКЧШМК

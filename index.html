🧠 Логика работы нейросети (по аналогии с линейной регрессией и деревом решений)

Если линейная регрессия ищет «лучшую прямую» (y = wx + b), а дерево решений строит цепочку вопросов «Если → То», то нейросеть объединяет тысячи простых нейронов в многослойную структуру, способную аппроксимировать зависимости любой сложности.

🔹 Как работает один нейрон:

  1. Получает входы: x₁, x₂, ... xₙ
  2. Умножает на веса: w₁, w₂, ... wₙ (важность признаков)
  3. Суммирует со смещением: Z = Σ(xᵢ·wᵢ) + b (как в линейной регрессии)
  4. Пропускает через функцию активации (ReLU, Sigmoid) — добавляет нелинейность
  5. Передаёт результат следующему слою

🔹 Как сеть учится (Backpropagation):

  1. Прямой проход: данные проходят через слои → получается прогноз
  2. Расчёт ошибки: сравниваем прогноз с правильным ответом (Loss Function)
  3. Обратный проход: вычисляем градиенты — как каждый вес повлиял на ошибку
  4. Корректировка: обновляем веса через Gradient Descent, чтобы уменьшить ошибку
  5. Повторяем миллионы раз → веса «настраиваются» под данные
Модель Логика Плюсы
Линейная регрессия Одна прямая линия Проста, интерпретируема
Дерево решений Последовательность правил «Если → То» Наглядна, работает с нелинейными данными
Нейросеть Многослойная композиция нелинейных функций Универсальна, масштабируема, точна на сложных данных

💡 Ключевая идея: Нейросеть не ищет готовые правила — она сама формирует признаки через слои, превращая сырые данные в абстрактные представления, где задача становится линейно разделимой.
